# AI SQL Analytics Assistant

## Project Overview

AI SQL Analytics Assistant is an enterprise-style portfolio project that allows users to ask business questions in natural language. The application converts English questions into SQL queries using Google's Gemini LLM, executes them on a PostgreSQL database, and presents interactive visualizations along with AI-generated business insights.

---

## Objectives

- Convert Natural Language into SQL
- Execute SQL securely
- Display Interactive Charts
- Generate AI Business Insights
- Build a production-style analytics application
